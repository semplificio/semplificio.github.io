Come aprire un file P7M

Guida Semplificio · aggiornata a ottobre 2026

Se ricevi fatture elettroniche, prima o poi ti capita un file che termina con .xml.p7m: un doppio clic non lo apre e Windows non sa con quale programma leggerlo. Niente paura: dentro c'è una normalissima fattura.

Cos'è un file P7M

Un file P7M è una busta firmata digitalmente (formato CAdES). Contiene il documento originale, nel caso delle fatture il file XML in formato FatturaPA, più la firma digitale di chi l'ha emesso. La firma garantisce chi ha creato il documento e che nessuno l'ha modificato dopo.

Per questo il nome ha due estensioni: fattura.xml.p7m significa "il file fattura.xml, firmato".

Come aprirlo

1. Con il programma della tua firma digitale

Chi ha una firma digitale ha di solito anche il software per verificarla, fornito da chi ha rilasciato la firma. Questi programmi aprono i file .p7m, verificano la firma e permettono di salvare il documento originale contenuto nella busta.

2. Con un visualizzatore online

Esistono siti che aprono i file P7M e mostrano la fattura in modo leggibile. Sono comodi per una fattura ogni tanto. Ricorda però che una fattura contiene dati personali e commerciali: carica solo documenti che puoi condividere con un sito esterno.

3. Con il portale dell'Agenzia delle Entrate

Se la fattura è passata dal Sistema di Interscambio, la trovi anche nell'area riservata "Fatture e Corrispettivi" del sito dell'Agenzia delle Entrate, dove puoi consultarla.

E se le fatture sono tante?

Aprire i P7M uno alla volta va bene per poche fatture. Se ne hai decine o centinaia e ti serve un riepilogo, conviene un programma che legga direttamente tutti i file, P7M compresi, e li metta in un foglio di calcolo.

Fatture in Excel converte in un clic le fatture XML e P7M (anche lo zip del Cassetto fiscale) in un file Excel con dettaglio IVA e riepiloghi. Funziona sul tuo computer, senza caricare le fatture online.
