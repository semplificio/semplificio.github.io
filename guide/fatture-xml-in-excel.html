Fatture elettroniche XML in Excel: 3 metodi

Guida Semplificio · aggiornata a ottobre 2026

Le fatture elettroniche sono file XML: perfetti per i computer, scomodi per le persone. Se vuoi controllare le spese per fornitore, l'IVA del trimestre o preparare un riepilogo per il commercialista, ti serve un foglio Excel con una riga per fattura. Ecco tre modi per ottenerlo.

1. Esportazione dal gestionale o dal programma di fatturazione

Se usi un gestionale o un servizio di fatturazione elettronica, controlla prima se ha una funzione di esportazione in Excel o CSV. È la strada più veloce. Spesso però esporta solo alcuni campi, per esempio i totali senza il dettaglio IVA, e non serve se le fatture le hai solo come file.

2. Power Query di Excel

Excel ha uno strumento integrato, Power Query, che può importare più file da una cartella: menu Dati → Recupera dati → Da file → Da cartella. Con i file XML funziona, ma richiede pazienza:

  • la struttura di una fattura elettronica è annidata (intestazione, corpo, righe, riepiloghi IVA) e va "espansa" a mano, livello per livello;
  • le fatture con più aliquote IVA producono più righe per la stessa fattura;
  • i file .p7m firmati non sono leggibili direttamente: vanno prima estratti uno per uno;
  • se cambia qualcosa nei file, la query può smettere di funzionare.

È una buona soluzione se conosci Power Query e hai fatture sempre uguali.

3. Un programma dedicato

Un convertitore pensato per la FatturaPA fa tutto il lavoro: legge XML e P7M, anche dentro gli zip, riconosce fatture semplificate e note di credito, e crea un foglio già ordinato.

Fatture in Excel converte in un clic le fatture XML e P7M (anche lo zip del Cassetto fiscale) in un file Excel con dettaglio IVA e riepiloghi. Funziona sul tuo computer, senza caricare le fatture online.
